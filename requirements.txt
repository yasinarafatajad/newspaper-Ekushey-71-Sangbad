# MASTER PROMPT — PREMIUM BANGLADESHI NEWSPAPER HOMEPAGE REDESIGN

Redesign the **homepage only** of this existing Bangladeshi online newspaper website.

The goal is to transform the current homepage into a **luxury, premium, editorial-grade digital newspaper experience** that feels established, credible, sophisticated, and distinctly Bangladeshi.

The website should NOT look like a generic SaaS dashboard, blog, news template, or startup landing page.

It should feel like a serious **modern newspaper publication** with strong editorial identity.

---

## 1. CORE DESIGN DIRECTION

Create a visual language inspired by:

* Premium international newspapers
* High-end editorial magazines
* Contemporary Bangladeshi newspapers
* Luxury print publications translated into digital
* Strong newspaper grid systems
* Editorial photography
* Sophisticated typography
* Large headlines
* Carefully controlled whitespace
* Strong content hierarchy

The overall feeling should be:

**Luxury + Editorial + Trustworthy + Modern + Serious + Bengali**

Avoid making it overly flashy.

Premium should come from:

* Typography
* Spacing
* Grid structure
* Image treatment
* Content hierarchy
* Fine borders
* Editorial composition
* Consistency

NOT from excessive gradients, glassmorphism, glowing effects, huge rounded cards, or unnecessary animations.

---

# 2. IMPORTANT — PRESERVE THE EXISTING BRAND

## DO NOT CHANGE THE EXISTING COLOR SCHEMA

The project already has an established color system.

You MUST inspect the existing codebase and identify:

* Primary color
* Secondary color
* Accent color
* Background colors
* Text colors
* Border colors
* Muted colors
* Dark/light theme colors if available

Use the existing color variables/classes throughout the redesign.

Do NOT randomly introduce a new color palette.

Do NOT replace the brand colors with generic:

* Blue news colors
* Red news colors
* Black/yellow combinations
* Random gradients

The existing brand identity must remain recognizable.

You may improve how the existing colors are used through:

* Better contrast
* More restrained application
* Typography hierarchy
* Background layering
* Borders
* Accent usage
* Editorial emphasis

The redesign should feel like an evolution of the existing brand, not a completely different brand.

---

# 4. OVERALL VISUAL STYLE

The visual language should be:

### Editorial

Strong headlines and carefully structured content.

### Premium

Generous whitespace, refined typography, subtle borders and sophisticated composition.

### Newspaper-like

Dense enough to communicate substantial journalism, but never visually chaotic.

### Modern

Responsive layout, contemporary cards, modern interactions and clean implementation.

### Serious

Avoid playful UI patterns.

### Local

The experience should feel designed for Bangladeshi readers, not a foreign news template translated into Bangla.

---

# 5. HOMEPAGE STRUCTURE

Redesign the homepage into a sophisticated editorial flow.

Use multiple clearly separated sections.

Suggested structure:

---

## SECTION 01 — TOP UTILITY BAR

Create a very subtle utility bar.
Keep this extremely restrained.
It should feel like a newspaper information strip rather than a website navbar.

---

# SECTION 02 — MAIN HEADER / MASTHEAD

This should be one of the strongest visual areas of the homepage.

Create a premium newspaper-style masthead.

Include:

* Newspaper logo
* Brand name
* Main navigation
* Search
* Menu
* Login/profile if already supported
* Theme toggle if already supported

The logo should have strong visual authority.

Avoid making the header look like a typical SaaS navbar.

Think:

**newspaper masthead + modern digital navigation**

Use subtle separators and strong horizontal alignment.

---

# SECTION 03 — BREAKING / IMPORTANT NEWS TICKER

Create a sophisticated breaking-news strip.

Instead of an aggressive red alert design, use a refined editorial treatment.

Example:

BREAKING NEWS

[headline]

The ticker should feel integrated into the newspaper layout.

Use animation only if the existing project already supports it or if it can be implemented cleanly.

Do not make the ticker visually distracting.

---

# SECTION 04 — HERO EDITORIAL GRID

This is the most important section.

Do NOT use a simple single hero card.

Create a sophisticated editorial grid.

Example structure:

```text
┌──────────────────────────────┬───────────────┐
│                              │               │
│       MAIN NEWS IMAGE        │   SECONDARY   │
│                              │     STORY     │
│                              │               │
│   Large Bengali headline     ├───────────────┤
│   Description                │   SECONDARY   │
│   Category / time            │     STORY     │
│                              │               │
└──────────────────────────────┴───────────────┘
```

The primary story should receive significantly more visual weight.

Use:

* Large editorial image
* Large Bengali headline
* Short summary
* Category
* Published time
* Author if available

The primary headline should feel like a newspaper front-page headline.

Do not overuse rounded cards.

Prefer:

* sharp or subtly rounded corners
* thin borders
* clean image crops
* strong typographic hierarchy

---

# SECTION 05 — TOP STORIES

Create a "Top Stories" or equivalent section using the site's existing terminology.

Use a newspaper-style grid rather than identical cards.

Possible layout:

```text
Large story
      +
3 smaller stories
      +
secondary headlines
```

Vary visual sizes based on editorial importance.

The UI should communicate:

**not every story has equal importance.**

This is extremely important for a premium newspaper design.

---

# SECTION 06 — CATEGORY NAVIGATION

Create a refined horizontal category navigation area.

Example:

জাতীয় | রাজনীতি | আন্তর্জাতিক | অর্থনীতি | খেলাধুলা | বিনোদন | প্রযুক্তি | আরও

It should be:

* clean
* compact
* horizontally scrollable on mobile
* visually connected to the newspaper identity

Avoid giant pill-shaped buttons.

---

# SECTION 07 — LATEST NEWS

Create a professional latest-news section.

Use a dense editorial list.

Each item can contain:

* Thumbnail
* Category
* Headline
* Short metadata
* Published time

Example:

```text
[IMAGE]  জাতীয়
         বড় খবরের শিরোনাম এখানে
         ১২ মিনিট আগে
────────────────────────────
[IMAGE]  অর্থনীতি
         নতুন অর্থনৈতিক সিদ্ধান্ত...
         ২৮ মিনিট আগে
```

The section should feel information-rich without feeling cluttered.

---

# SECTION 08 — BANGLADESH / NATIONAL NEWS

Create a dedicated national-news section.

This should have stronger visual emphasis because the publication is Bangladeshi.

Use a sophisticated editorial grid.

Potential structure:

```text
Section title
────────────────────────────

Large national story | 3 smaller stories
                   |
                   | 2 headline lists
```

Use actual existing news data.

Do NOT create fake content just to fill the design.

---

# SECTION 09 — POLITICS

Create a dedicated politics section if the existing website has politics content.

Keep it editorially serious.

Do not use excessive red or dramatic visual treatments.

Use:

* Large headline
* Relevant image
* Smaller related headlines
* Publication metadata

The design should communicate importance without sensationalism.

---

# SECTION 10 — BUSINESS / ECONOMY

Create a premium financial-news section.

Possible content:

* Economy
* Business
* Market
* Banking
* Industry

Use a slightly more structured and data-oriented visual style while still maintaining the overall newspaper identity.

If the existing website already has financial data, preserve it.

---

# SECTION 11 — INTERNATIONAL

Create an international news section.

Use a strong editorial image and multiple supporting headlines.

The layout should maintain the same visual language while allowing this section to feel distinct through composition rather than a different color scheme.

---

# SECTION 12 — SPORTS

Create a visually stronger sports section.

Use:

* Large sports image
* Featured headline
* Supporting stories
* Match/news information if already available

Do not turn this into a sports-app interface.

It must still look like part of the newspaper.

---

# SECTION 13 — ENTERTAINMENT / LIFESTYLE

Create a more image-focused editorial section for:

* Entertainment
* Lifestyle
* Culture
* Celebrity
* Food
* Travel

Use larger imagery and more expressive layouts while preserving the newspaper's overall visual system.

---

# SECTION 14 — OPINION / EDITORIAL

If the existing website contains opinion/editorial content, give it a distinct editorial treatment.

Possible structure:

* Editorial
* Column
* Opinion
* Analysis

Use typography and whitespace to make this section feel more intellectual and publication-oriented.

Avoid making it look like another generic news-card grid.

---

# SECTION 15 — PHOTO / FEATURED STORIES

Create an image-heavy editorial section for important visual stories.

Use a magazine-like composition.

Large photography should be treated as an editorial asset.

Avoid unnecessary overlays and excessive gradients.

---

# SECTION 16 — NEWSLETTER / SUBSCRIPTION

If newsletter or subscription functionality already exists, redesign it as a premium editorial CTA.

Keep it subtle.

Example concept:

"সকালের গুরুত্বপূর্ণ খবর আপনার ইনবক্সে"

Do not make it look like a SaaS marketing section.

---

# SECTION 17 — FOOTER

Create a large, sophisticated newspaper footer.

Include existing:

* Categories
* Important pages
* About
* Contact
* Privacy Policy
* Terms
* Social links
* Copyright
* Publisher information
* Editorial information if available

The footer should feel like the final page of a premium publication.

---

# 6. TYPOGRAPHY

Typography is one of the most important parts of this redesign.

Because this is a Bangladeshi newspaper, prioritize excellent **Bangla typography**.

Inspect the existing fonts first.

If the project already has a suitable Bangla font, preserve it.

If typography can be improved, use a professional Bangla typeface suitable for editorial publishing.

The hierarchy should be approximately:

### Newspaper masthead

Strong / distinctive

### Hero headline

Very large and bold

### Section heading

Strong but restrained

### Story headline

Medium-large

### Summary

Comfortable reading size

### Metadata

Small and subtle

Do not use too many font families.

Prefer:

**1 primary Bangla editorial font + 1 supporting Latin font**

if necessary.

---

# 7. HEADLINE DESIGN

Bangla headlines must remain highly readable.

Use:

* Strong weight
* Appropriate line-height
* Controlled max-width
* Proper letter spacing
* Clear hierarchy

Avoid:

* Excessive uppercase styling
* Artificial letter spacing
* Tiny text
* Long paragraphs
* Excessive text overlays on images

The headline should remain the primary visual communication method.

---

# 8. IMAGE DIRECTION

Images are extremely important.

Use existing article images from the application's data.

Image treatment should feel editorial.

Prefer:

* large crops
* consistent aspect ratios
* high-quality photography
* intentional focal points
* subtle hover transitions

Avoid:

* random image heights
* stretched images
* low-quality placeholders
* excessive gradients
* decorative stock photography
* laptop/device mockups
* artificial 3D illustrations

---

# 9. CARD DESIGN

Do NOT make every article a card.

A premium newspaper should combine:

* editorial grids
* lists
* bordered stories
* image stories
* headline blocks
* compact rows
* featured articles

Use cards only when they improve information hierarchy.

Avoid the common:

```text
┌─────────────┐
│ Image       │
│             │
│ Title       │
│ Description │
│ Button      │
└─────────────┘
```

repeated 20 times across the homepage.

That makes the site look like a generic template.

---

# 10. BORDERS & DIVIDERS

Use thin editorial dividers extensively.

Examples:

```text
────────────────────────────────
```

and:

```text
│
```

Use the existing border color.

Borders should create structure without becoming visually heavy.

This is an important part of achieving the newspaper aesthetic.

---

# 11. WHITESPACE

Use intentional whitespace.

Do not compress everything just because it is a news portal.

Premium design requires breathing room.

However, maintain enough information density that the website still feels like a newspaper.

The target balance:

**High information density + high visual discipline**

---

# 12. RESPONSIVE DESIGN

The homepage must be fully responsive.

### Desktop

Use sophisticated editorial grids.

Possible:

* 12-column grid
* 8-column editorial layouts
* asymmetric layouts
* large hero stories

### Tablet

Collapse grids intelligently.

### Mobile

Do NOT simply shrink the desktop layout.

Create a dedicated mobile editorial hierarchy.

Example:

```text
Masthead
↓
Breaking news
↓
Main story
↓
Secondary stories
↓
Latest news
↓
Categories
↓
National
↓
Politics
↓
Business
...
```

On mobile:

* Headlines remain readable
* Images remain meaningful
* Navigation becomes horizontally scrollable
* No horizontal overflow
* No tiny text
* No excessive card nesting
* Touch targets remain accessible

---

# 13. ANIMATION

Keep animations extremely subtle.

Allowed:

* opacity transitions
* small image scale on hover
* underline transitions
* navigation transitions
* smooth ticker movement

Avoid:

* bounce
* excessive parallax
* floating elements
* dramatic entrance animations
* spinning elements
* excessive zoom
* flashy effects

The website should feel like a publication, not a motion-design showcase.

---

# 14. DARK MODE

If the existing project already supports dark mode:

Preserve it.

Do NOT redesign the dark mode from scratch unless necessary.

Make sure:

* text contrast is excellent
* images remain visually strong
* borders remain visible
* existing brand colors remain consistent
* backgrounds are sophisticated
* no pure-black/pure-white abuse unless already part of the system

---

# 15. CONTENT HANDLING

IMPORTANT:

Use the existing API/data architecture.

Do NOT replace the existing news data system.

Do NOT create a new backend.

Do NOT modify unrelated functionality.

Do NOT hardcode fake news if real data already exists.

The redesign should consume the existing:

* news data
* categories
* images
* authors
* timestamps
* API responses
* existing components

If mock data is already part of the homepage, identify whether it should be replaced with existing production data.

* Carefully controlled image ratios
* Small category labels
* Subtle timestamps
* Refined hover states
* Elegant separators

---

# 22. DESIGN PHILOSOPHY

The homepage should communicate:

> "This is a serious publication people trust for their daily news."

It should feel like a digital newspaper that has evolved from traditional editorial design into a modern web experience.

The design should not scream for attention.

It should **earn attention through hierarchy, typography, photography, and composition.**

---

# 23. IMPLEMENTATION PROCESS

Before writing code:

### Step 1

Inspect the existing project.

Understand:

* framework
* routing
* existing homepage
* color variables
* typography
* API structure
* components
* existing news data
* image handling
* dark mode
* responsive behavior

### Step 2

Identify what can be reused.

Do not unnecessarily rebuild:

* API calls
* authentication
* navigation logic
* data fetching
* existing reusable components
* SEO
* theme system

### Step 3

Plan the new homepage hierarchy.

### Step 4

Implement the visual redesign.

### Step 5

Test:

* desktop
* tablet
* mobile
* light mode
* dark mode
* loading states
* empty states
* long Bangla headlines
* missing images
* different article counts

### Step 6

Polish typography, spacing, borders and image ratios.

# 24. FINAL QUALITY BAR

When finished, compare the result against this question:

**Does this look like a premium Bangladeshi newspaper publication, or does it look like a generic news website template?**

If it looks generic, continue refining the:

* editorial hierarchy
* typography
* grid
* spacing
* image composition
* section separation
* navigation
* masthead

The final result should feel:

**Premium. Editorial. Bengali. Trustworthy. Modern. Sophisticated. Newspaper-first.**

Do not change the site's existing brand colors.

Do not modify unrelated pages or functionality.

Work primarily on the **homepage UI/UX and its presentation layer** while preserving the existing application's architecture and functionality.
